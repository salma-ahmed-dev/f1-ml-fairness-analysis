# Dataset

The analysis expects a CSV called `f1_pitstops_2018_2024.csv` in this folder.

The original dataset used in the university notebook contains race and pit stop information from 2018 to 2024. The columns used by the cleaned script are:

`Stint Length`

`Air_Temp_C`

`Tire Compound`

`Constructor`

`Lap Time Variation`

I have not added the raw CSV here yet. I want to check the original source and redistribution terms before publishing it separately from the university project.
